# Supplementary material — From Code to Intent: A Survey of Attack and Anomaly Detection in Decentralized Finance

Works are named by short name and identifier (a DOI, else an arXiv id, a URL, or venue and year). S2's ref column also gives each placed work's reference number, the one Table 4 or Supplementary Table 7 prints: its number in the article's reference list or, for a work that only the supplement cites, its number in the supplement's own list ([S1], [S2], ...). Works not peer-reviewed at the time of writing were read during the search and are excluded by rule (Supplementary Appendix D.5; S1.5).
